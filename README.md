# 🪵 SpotClick - Catálogo & Portfólio de Móveis em Madeira Maciça

Site e portfólio de alta performance da **SpotClick**, fabricante de móveis e decorações artesanais em madeira maciça de pinus de reflorestamento, pronto para deploy na **Vercel**.

---

## 🚀 Como Rodar Localmente

1. Abra a pasta do projeto:
```bash
cd C:\Users\User\spotclick
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Acesse no navegador:
```
http://localhost:5173
```

---

## 🌐 Como Fazer o Deploy na Vercel

O projeto já possui `vercel.json` configurado e scripts otimizados para deploy em 1 clique.

### Opção 1: Via Vercel CLI (Super rápido)
No terminal, dentro da pasta `C:\Users\User\spotclick`:
```bash
npx vercel
```
- Siga as instruções na tela (pressione Enter para aceitar as opções padrão).
- Seu site estará online em segundos com URL gratuita `.vercel.app` e SSL automático!

Para deploy em produção definitivo:
```bash
npx vercel --prod
```

### Opção 2: Via GitHub + Vercel Dashboard
1. Crie um repositório no seu GitHub.
2. Faça o push dos arquivos:
```bash
git remote add origin https://github.com/SEU-USUARIO/spotclick.git
git branch -M main
git push -u origin main
```
3. Acesse [vercel.com](https://vercel.com), clique em **"Add New Project"**, selecione o repositório e clique em **"Deploy"**.
